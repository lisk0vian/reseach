## Project context
Before exploring `data/` or `papers/drafts/` for background information, 
always check `context/` first.

The `context/` folder contains markdown versions of key project documents, 
converted with markitdown and pandoc to reduce token usage. Use these 
files instead of opening the original source documents (.xlsx, .docx, .doc) 
whenever you need background, definitions, or content from those sources.

- `context/INDEX.md` lists every file in context/, its original source, 
  an approximate token count, and a one-line description. Read INDEX.md 
  first to decide which file(s) are actually relevant before opening them.
- Raw CSVs in `data/` are used directly by notebooks and do NOT have a 
  markdown version in context/ — read them normally when working with 
  notebooks/experiments.ipynb.
- Do not answer questions about project background, methodology, or the 
  paper drafts by exploring the whole repo — check context/INDEX.md first.
- `context/experiments.md` is a markdown mirror of `notebooks/experiments.ipynb`
  and is NOT listed in INDEX.md. Use it to read pipeline code without loading
  the 9.8 MB notebook.

### Known provenance traps

- **`derived_dca.csv` and `derived_strata.csv` are reconstructions**, not raw
  outputs. `make_figures.py` rebuilds the decision curve from the 10 fixed-width
  reliability bins of `Tabla_49`, rounding `n × observed_rate` to integers. The
  τ = 0.65 row alone comes from the exact confusion matrix of `Tabla_73`. The
  grid therefore cannot be refined below steps of 0.10, and rows on the grid are
  bin-rounded. Any statement about the DCA must respect this.
- **`Tabla_72`** records all 8 models as omitted from external validation with
  reason `name 'append_to_csv' is not defined`. This is a logging bug, not a
  feature mismatch (`features_modelo` = `features_external` = 74); `Tabla_71`
  holds the real 2026 metrics. Fix the bug before publishing the notebook.
- **`Tabla_03`** says all 8 years come from one consolidated
  `Data_Final_Casos_Fiscales_Ene_2019-May_2026.csv`, but `data/` holds eight
  per-year CSVs and the consolidated file is not in the repo.

## Springer manuscript: `papers/drafts/springer/`

Target: **Journal of Big Data** (SpringerOpen, ISSN 2196-1115), article type
**Methodology**. Guidelines: <https://link.springer.com/journal/40537/submission-guidelines>

### Before touching the preamble, read the official template

`papers/templates/springer-nature-latex-template-master/sn-article.tex` is the
official Springer Nature template, with `user-manual.pdf` alongside it. **Check
it before adding any package** — `sn-jnl.cls` already provides most of what a
submission needs as class options, and doing it by hand is worse:

| Need | Correct way | Do NOT |
|---|---|---|
| Double-line spacing | `referee` class option | load `setspace` yourself — same effect, but the option is what the template documents |
| Line numbers in margin | `lineno` class option | load the `lineno` package — the class uses its own `vruler` and the generic package can break display math |
| ORCID | editorial system, or a comment in the `.tex` | `\orcid{}` — it needs an `Orcidlogo.eps` that is not shipped here |

`referee` is a plain global `\doublespacing` (`sn-jnl.cls:124-129`) and applies to
body text, tables and captions alike. The `\singlespacing` guarded by
`\if@referee` at line 706 affects only the article-category box on the front
page — it does **not** protect the title block or abstract.

Current line — **both options deliberately off**, by author preference, so the
output matches the stock template:
```latex
\documentclass[sn-vancouver,Numbered]{sn-jnl}
```
Do not re-add either without being asked. The option list for each state is kept
as comments directly above that line in `main.tex`:

| State | Options | Pages |
|---|---|---|
| Current — matches the stock template | `sn-vancouver,Numbered` | 39 |
| Editorial submission (JBD asks for both) | `sn-vancouver,Numbered,referee,lineno` | 56 |

The large empty band at the foot of every page is the SN class's own type area on
A4 and appears identically in `sn-article.pdf`. It is not a bug; do not try to
"fix" it with geometry changes.

`breakurl` warns under pdfLaTeX. This comes from `sn-jnl.cls` itself (line 1462);
it is benign and must not be "fixed" by editing the class.

### Journal formatting rules that are easy to break

- **No commas in numerical values inside tables.** Use `9593`, not `9{,}593`,
  anywhere inside a `table` environment. Body text may keep `{,}`.
- **Figure captions need a short title (≤15 words) plus a legend.** The pattern
  in use is `\caption[Short title]{\textbf{Short title.} Legend…}`.
- **Table titles ≤15 words**, legends below, no colour or shading.
- Figures: ~300 dpi at final size, 85 mm or 170 mm wide, under 10 MB, uploaded
  as separate files in order.
- **Declarations headings are fixed and ordered**: Ethics approval and consent to
  participate · Consent for publication · Availability of data and materials ·
  Competing interests · Funding · Authors' contributions · Acknowledgements ·
  Authors' information (optional). `Acknowledgements` goes *inside* Declarations.
  There is no "Code availability" heading — code goes under *Availability of data
  and materials*.
- A **List of abbreviations** section is mandatory when abbreviations appear.
- Web references need an access date.
- Use of LLMs must be disclosed in the Methods section.
- A cover letter is mandatory (`cover_letter.md` holds the draft).

### Building

`latexmk` fails here because bibtex cannot resolve `BSTINPUTS` under Git Bash.
Compile like this instead:

```bash
cd papers/drafts/springer
mkdir -p build2 && cp references.bib sn-vancouver.bst build2/
pdflatex -interaction=nonstopmode -output-directory=build2 main.tex
(cd build2 && bibtex main)
pdflatex -interaction=nonstopmode -output-directory=build2 main.tex
pdflatex -interaction=nonstopmode -output-directory=build2 main.tex
```

Then copy `main.pdf` and `main.bbl` up to the folder root and into `build/`.
`build/main.aux` sometimes holds a Windows file lock; compiling into a fresh
directory avoids it.

Acceptance bar for any edit: **0 errors, 0 undefined references or citations,
0 overfull hboxes.**

### Figures

All ten are generated by `make_figures.py` from `src/tables/*.xlsx`. **Never edit
a PNG by hand and never hard-code a number into the script** — read it from the
table so figures and manuscript cannot drift apart. Rerun with
`python make_figures.py`; it also rewrites `derived_dca.csv` and
`derived_strata.csv`.

Constraints that are already satisfied and must stay satisfied:

- **Two data hues only** — `BLUE #1f5c99` and `ORANGE #c2571a`. They pass all six
  checks of the dataviz palette validator against a white surface (worst adjacent
  pair ΔE 20.4 protan, 28.7 normal vision). A third data hue does not pass
  alongside them, so a figure needing three series uses **small multiples**
  instead (this is why Fig. 4 is three stacked panels rather than three lines).
- **Colour follows the entity.** The τ = 0.65 operating point in Fig. 8 is blue
  because it belongs to the model series; painting it orange assigns it to the
  "flag every unit" strategy. Where a quantity has a sign, use the diverging
  form (blue below zero, orange above, neutral rule at zero) — Fig. 6b/6c and
  Fig. 10.
- **Text never wears a series colour.** Annotations and direction keys stay in
  `INK` or `MUTED`.
- **The partial 2026 file is always marked** wherever it is plotted next to
  complete years: `PARTIAL` wash, hollow marker, dashed connector, and excluded
  from any quoted range. Joining it with a solid line asserts a trend the text
  denies.
- **Encode weight, not just magnitude.** Fig. 6 exists in three panels because a
  signed-deviation panel alone gives the tallest bar to a bin holding 10 units
  while the bin holding 932 looks negligible.
- **Width ≤ 170 mm at 300 dpi (≤ 2008 px).** `savefig.bbox="tight"` expands past
  `figsize`, so measure after generating:
  ```bash
  python -c "from PIL import Image;import glob,os;[print(os.path.basename(f), Image.open(f).size[0]/300*25.4) for f in sorted(glob.glob('figures/*.png'))]"
  ```
- **Look at every regenerated figure** before calling it done. The palette
  validator checks colour, not layout; label collisions are found only by
  opening the PNG.

### Editing the `.tex`

- Use the Edit tool, not `sed`. Git Bash mangles backslashes in LaTeX, and
  heredocs collapse `\\` in Python regexes.
- When writing a checker script, strip comments with `(?<!\\)%.*`, never `%.*` —
  the latter truncates lines at `95\%` and silently loses everything after it.

## Methodological commitments the manuscript makes

These are load-bearing. Do not weaken them, and do not introduce text that
contradicts them.

1. **2026 is exploratory only.** The file covers January–May. It must never
   support a performance claim. In particular, the walk-forward ranges quoted in
   the text cover the **six** complete-year folds (2020–2025); `Tabla_34`'s
   seventh fold evaluates 2026 and is excluded from every range.
2. **2025 is the single locked evaluation.** Model family selection was closed on
   training-block walk-forward CV before 2025 was opened. Table 5 is a single
   simultaneous evaluation reported descriptively; no decision follows from it.
3. **The reported model is not recalibrated.** Calibration is measured and
   characterised, never corrected. Never state or imply recalibrated performance.
4. **Risk bands are on the uncalibrated scale** and are described on the same
   partition they were derived from. They are not a validated triage instrument.
5. **The three surviving publication-metadata indicators are reported, not
   fixed.** They are identically zero across 2024–2026, so no reported figure is
   affected, but they absorbed year-specific variation during training. The
   manuscript treats this as its clearest evidence that an availability criterion
   must be verified against the fitted feature matrix, not the exclusion rule.
6. **The ablation is a LightGBM result**, and every mention of it must say so.
7. **Report discrimination, calibration and utility separately.** Never
   summarise them into one figure of merit; where they conflict, the most
   conservative governs.
