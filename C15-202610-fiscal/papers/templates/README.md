# Templates for Journal of Big Data Submission

This directory contains templates and guidelines for preparing your manuscript for submission to the **Journal of Big Data** (Springer, SpringerOpen).

## Contents

- **`springer-nature-latex-template-master/`** — Official Springer Nature LaTeX template
  - **Main files to use**:
    - `sn-article.tex` — Example research article (copy as your main manuscript file)
    - `sn-jnl.cls` — Document class (required)
    - `sn-vancouver.bst` — Bibliography style (use for Journal of Big Data citations)
    - `sn-bibliography.bib` — Example bibliography
    - `user-manual.pdf` — Complete LaTeX template usage guide
    - `sn-article.pdf` — Rendered output example

- **`JOURNAL_OF_BIG_DATA_REQUIREMENTS.md`** — Complete submission guidelines
  - Format requirements (abstract, keywords, structure)
  - Figures, tables, and references formatting
  - Citation style (Vancouver)
  - Data availability requirements
  - Competing interests and funding declarations
  - **READ THIS FIRST** before preparing your manuscript

## Quick Start

### For LaTeX Users
1. Read `JOURNAL_OF_BIG_DATA_REQUIREMENTS.md` (this document)
2. Copy `springer-nature-latex-template-master/sn-article.tex` as your main file
3. Replace placeholder text with your content
4. Use `sn-vancouver.bst` bibliography style
5. Compile: `pdflatex + bibtex + pdflatex`
6. Or use Overleaf: https://www.overleaf.com/latex/templates/springer-nature-latex-template/myxmhdsbzkyd

### For Word Users
1. Download template from: https://www.springer.com/gp/authors-editors/journal-author/word-template-zip-154-kb-/22044
   - Or contact Springer Support: https://support.springernature.com/en/support/solutions/articles/6000081241-templates-and-style-files-for-journal-article-preparation
2. Use Vancouver reference style (numbered citations)
3. Follow all formatting rules in `JOURNAL_OF_BIG_DATA_REQUIREMENTS.md`

## Key Requirements Summary

| Requirement | Specification |
|---|---|
| **Abstract** | 150–250 words (no references) |
| **Keywords** | 3–10 keywords |
| **References Style** | Vancouver (numbered) |
| **Figure Titles** | Max 15 words |
| **Figure Legends** | Max 300 words |
| **Table Titles** | Max 15 words |
| **Table Legends** | Max 300 words |
| **Word Limit** | None (no restriction) |
| **File Format** | Editable (DOCX or TEX) — NOT PDF |
| **Competing Interests** | Mandatory declaration |
| **Funding** | Mandatory declaration |
| **Data Availability** | Required statement + public repository links |

## Submission Checklist

- [ ] Read `JOURNAL_OF_BIG_DATA_REQUIREMENTS.md` completely
- [ ] Manuscript in concise English
- [ ] Abstract 150–250 words (no citations)
- [ ] Keywords: 3–10
- [ ] All figures numbered and referenced
- [ ] All tables in manuscript (not as images)
- [ ] References in Vancouver style (numbered)
- [ ] No URLs in text (all in reference list)
- [ ] Competing Interests section completed
- [ ] Funding section completed
- [ ] Data Availability statement with repository links
- [ ] Editable files only (LaTeX .tex or Word .docx)
